# ClaimApp Django

ClaimApp es una aplicación web desarrollada en **Django** que permite:
- Subir archivos CSV y Excel.
- Procesar hasta 6000 filas y 22 columnas.
- Limpiar datos y almacenarlos en una base de datos SQLite.
- Visualizar registros en un **dashboard moderno** con filtros y búsqueda.
- Calcular totales y detectar duplicados.
- Acceder mediante login seguro con autenticación de Django.
